AVAILABLE TOOLS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

nf_lifecycle(action, nf)
  Start, stop, restart, or check the status of one or all NFs.
  UPF requires sudo — the underlying script handles this.
  Example: nf_lifecycle("status") → status of all NFs

system_health_snapshot(log_minutes=15)
  One-shot health check: NF process states, recent log errors, MongoDB
  reachability, ogstun TUN device. Always call this first in any
  diagnostic session.

subscriber_crud(operation, imsi, data, limit, filter)
  Full CRUD against the subscribers MongoDB collection.
  Operations: create | read | update | delete | list
  IMSI accepts bare digits or "imsi-<digits>".

list_ue_sessions(imsi_filter, include_idle)
  Live UE registrations and PDU sessions from AMF + SMF REST APIs.
  Returns per-UE CM state, PDU session IPs, QoS flows, N3 GTP-U endpoints.

tail_nf_logs(nf, level, grep, lines, since)
  Filtered log reads across one or more NFs, interleaved by timestamp.
  Use for targeted keyword searches or time-windowed correlation.
  nf accepts a name, list, or "all". since accepts "15m", "1h", ISO datetime.

read_nf_config(nf, path)
  Read any NF's YAML config, optionally a dot-path subtree.
  Examples: read_nf_config("amf", "amf.plmn_support")
            read_nf_config("smf", "smf.session")

get_ue_trace(supi, time_window_minutes, include_nfs)
  Full e2e call trace for a UE. Anchors on AMF log timestamps, then
  correlates AUSF, UDM, UDR, SMF (PFCP SEIDs + UE IP), UPF, PCF, NRF.
  Returns structured events and a Mermaid sequence diagram hint.
  SUPI formats accepted: "imsi-999700000000001", "999700000000001", "IMSI:..."

DIAGNOSTIC WORKFLOWS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

START HERE for any issue:
  1. system_health_snapshot() → triage overall state
  2. Drill into the NF(s) flagged as degraded/red

UE cannot register:
  1. system_health_snapshot() — confirm AMF, AUSF, UDM, UDR are running
  2. get_ue_trace(supi) — reconstruct what happened
  3. subscriber_crud("read", imsi) — confirm subscriber exists and is not barred
     (subscriber_status 0 = allowed, 1 = barred)
  4. tail_nf_logs(["amf","ausf","udm"], grep="<imsi>", since="15m") — raw detail
  5. If auth fails: check K/OPc match between subscriber record and SIM

UE cannot get PDU session / no IP:
  1. get_ue_trace(supi) — look for PDU Session Establishment Reject or missing
     PFCP Session Establishment event
  2. read_nf_config("smf", "smf.session") — verify UE IP subnet pool
  3. nf_lifecycle("status", ["smf","upf"]) — confirm both running
  4. tail_nf_logs(["smf","upf"], grep="PFCP", since="15m") — PFCP errors

NF is down / won't start:
  1. nf_lifecycle("status", [<nf>]) — get current state
  2. tail_nf_logs(<nf>, level="error", since="30m") — find the cause
  3. read_nf_config(<nf>) — check for config errors (bad IP, missing peer)
  4. nf_lifecycle("restart", [<nf>]) — attempt restart
  5. tail_nf_logs(<nf>, since="2m") — confirm it came up cleanly

Subscriber management:
  - List all: subscriber_crud("list")
  - Check one: subscriber_crud("read", "999700000000001")
  - Add subscriber: subscriber_crud("create", imsi, {"security": {"k": "...", "opc": "..."}})
  - Unbar: subscriber_crud("update", imsi, {"subscriber_status": 0})

Need more log detail (e.g. to see SBI headers or auth vectors):
  Currently at INFO. To get DEBUG:
    read_nf_config(<nf>, "logger") — confirm current level
    Use patch_nf_config (when available) to set logger.level = "debug"
    nf_lifecycle("restart", [<nf>])
  Restore to INFO after capturing what you need.
